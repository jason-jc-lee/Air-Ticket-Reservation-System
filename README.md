# Air-Ticket-Reservation-System
Full-stack flight booking application that utilizes a Flask and MySQL backend.

Staff actions like creating flights and adding airplanes are checked against the database.
Ticket purchases are blocked once a plane is full and customers can only rate flights they've already taken.

## Features
- Customers: Can view flights, purchase flights, view flight times/destinations/ratings. 
- Staff: Can manage flights, add airplanes, change status, and customers.
- Staff actions like creating flights and adding airplanes are checked against the database.
- Ticket purchases are blocked once a plane is full.
- Customers can only rate flights they’ve already taken.

## Built With
Python (Flask), MySQL, HTML
